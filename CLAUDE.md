An Android application that allows a user to track their daily habits.

It has the following features:

* Notifications - notifies the user when their habit is due
* Completion - allows the user to mark habits as completed for the current day
* Tracking - allows the user to track the status of habits over time, i.e. completed or not completed habits
* Export - allows the user to export the status of habits into a csv file

Technical Stack:

* Language: Kotlin
* UI Framework: No preference
* Architecture pattern: No preference
* Database: Room
* Notification Library: No preference

Project Setup:

* Minimum Android SDK version target: 35
